# Handoff — Dashboard Power BI (PBIP) do projeto capacitacao

## Objetivo
Gerar programaticamente um dashboard Power BI (formato PBIP) a partir da base
de capacitação em IA da ENAP, para abrir no Power BI Desktop sem montar nada na
UI. **Status atual: feature implementada, mergeada, e empacotada para o usuário
abrir no Windows.** A sessão está essencialmente concluída — pendente só a
validação visual no Power BI Desktop real (Windows), que o usuário fará.

## Decisões fechadas
- **PBIP (TMDL + PBIR), não PBIX** — único caminho text-first/programável da Microsoft.
- **Flat schema (single-table)**, não star schema — 385k linhas cabem em VertiPaq;
  evita TMDL de relacionamentos. NÃO re-discutir.
- **Fonte = `docs/dashboard_base.csv`** (fato), não o agregado — permite
  DISTINCTCOUNT de pessoas únicas com qualquer filtro.
- **CsvPath como parâmetro M** ajustado na 1ª abertura — Power Query não tem
  caminho relativo nativo ao .pbip; é workaround padrão, conhecido e documentado.
- **Slicers usam `ia_label`** ("IA"/"Não IA"), não o int `ia` — legibilidade.
- **lineageTag UUIDs persistidos** em `.lineage.json` — diffs git limpos.
- **Usuário optou por commitar TUDO** do working tree no PR #2 (incl. artefatos
  playwright e relatórios .html/.xlsx) — escolha explícita.
- **Usuário vai executar no Windows** (não macOS) — por isso o .zip com CSV junto.
